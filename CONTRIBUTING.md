# Как внести вклад в Gypsum

Спасибо за интерес! Вот короткая инструкция.

## Баг-репорты

Перед созданием issue:

1. Проверьте, что используете последнюю версию
2. Поищите похожую проблему в существующих issues
3. Приложите **текст ошибки из консоли** целиком
4. Опишите шаги для воспроизведения

## Фича-реквесты

Опишите:

- Какую задачу вы хотите решить
- Как это должно работать
- Почему это полезно другим мастерам

## Pull Request'ы

### Что приветствуется

- **Новые статьи в `library.json`** — техники, материалы, рецепты
- **Улучшения расчётов** — если нашли более точную формулу, покажите её
- **Новые материалы в seed** — с обоснованием цены
- **Исправления интерфейса** — если что-то неудобно
- **Темы оформления** — если сделаете красивую палитру

### Процесс

```bash
# 1. Форкните репозиторий
# 2. Создайте ветку
git checkout -b feature/название

# 3. Внесите изменения
# 4. Проверьте, что приложение запускается
python app.py

# 5. Закоммитьте
git commit -m "feat: добавлена статья про фьюзинг"

# 6. Пушните
git push origin feature/название

# 7. Откройте PR
