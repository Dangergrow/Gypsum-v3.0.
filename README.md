## 📖 О проекте

**Gypsum** — офлайн-приложение для мастеров, работающих с гипсом, литьевыми смолами и 3D-печатью. Помогает точно посчитать себестоимость изделия, вести учёт материалов и производства, а также содержит огромную встроенную библиотеку знаний по техникам и материалам.

Приложение не требует интернета, все данные хранятся локально в SQLite рядом с `.exe`. Никаких аккаунтов, никаких облаков, никакой телеметрии.

### Для кого

- 🎨 **Мастера hand-made** — гипсовые панно, барельефы, смоляные украшения
- 🏭 **Небольшие производства** — серийное литьё, тиражи, оптовые партии
- 🖨️ **3D-печатники** — расчёт FDM и SLA-печати с электричеством и амортизацией
- 📚 **Начинающие** — библиотека знаний заменит десяток открытых вкладок с рецептами

## ✨ Возможности

### 💰 Расчёты себестоимости

- **Гипсовые изделия** — вес гипса, авторасчёт воды по пропорции, армирование
- **Литьевые смолы** — компонент A + B с пропорцией, эпоксидка/полиуретан/полиэстер
- **3D-печать** — FDM (филамент) и SLA (фотополимер) в одном калькуляторе
- **Полная смета** — материал + потери + работа + электроэнергия + амортизация + упаковка + декор
- **Наценка и цена продажи** — считает прибыль в реальном времени
- **Произвольный декор** — бисер, стекляшки, клей, краски и любые доп. материалы

### 📚 Библиотека знаний

- **9 категорий, 40+ статей** — гипс, смолы, 3D-печать, формы, декор, инструменты, безопасность, бизнес, техники
- **Редактируется прямо в приложении** — правки сохраняются в БД
- **Поиск по содержимому** — по названию, тегам и тексту статьи
- **Закладки** — сохраните важное на потом
- **Обновление через `library.json`** — просто отредактируйте файл

### 📊 Учёт и производство

- **Шаблоны изделий** — сохраняйте типовые расчёты и запускайте их в один клик
- **Журнал производства** — что, когда, сколько и по какой цене изготовлено
- **Склад материалов** — остатки, минимумы, цветные индикаторы, предупреждения
- **Поставщики** — контакты, телефоны, сайты, заметки
- **Справочник материалов** — 29 позиций из коробки, полное редактирование

### 🎨 Интерфейс

- **5 тем оформления** — Light, Dark, Sepia, Nord, Plum
- **Полная русификация** — без англицизмов в интерфейсе
- **Плавные анимации** — переходы, hover-эффекты, появление карточек
- **Глобальные тултипы** — подсказки по любому элементу (не обрезаются)
- **Экспорт в PDF** — через системную печать (Ctrl+P)

### 💾 Данные

- **SQLite-база рядом с приложением** — портативность
- **Резервные копии в JSON** — экспорт/импорт всей базы одной кнопкой
- **Автосохранение черновика** — незаконченный расчёт не потеряется
- **Офлайн-режим** — не требует подключения к сети

## 🚀 Установка

### Требования

- **Python 3.8+** ([скачать](https://www.python.org/downloads/))
- **Windows 10/11**, macOS 10.13+, или Linux с GTK/Qt

### Способ 1 — из исходников (рекомендуется)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Dangergrow/gypsum.git
cd gypsum

# 2. Установить зависимости
pip install pywebview

# 3. Запустить
python app.py
```

### Способ 2 — готовая сборка

1. Скачайте `Gypsum.exe` из [Releases](https://github.com/Dangergrow/gypsum/releases)
2. Поместите `.exe` в отдельную папку
3. Запустите двойным кликом

База `gypsum.db` и папка `backups/` создадутся автоматически рядом с `.exe`.

### Быстрый запуск на Windows

Создайте файл `Запустить.bat` рядом с `app.py`:

```bat
@echo off
cd /d "%~dp0"
python app.py
pause
```

Теперь достаточно двойного клика по `.bat`.

## 📦 Сборка в .exe

```bash
pip install pyinstaller
```

Создайте `build.bat`:

```bat
pyinstaller --noconfirm --onefile --windowed ^
  --name "Gypsum" ^
  --icon "icon.ico" ^
  --add-data "index.html;." ^
  --add-data "library.json;." ^
  --add-data "icon.svg;." ^
  app.py
```

Готовый `.exe` появится в `dist/Gypsum.exe`.

### Иконка

Для `.exe` нужен `.ico`. Сконвертировать из `icon.svg` можно через:

- **[cloudconvert.com/svg-to-ico](https://cloudconvert.com/svg-to-ico)** — онлайн
- **ImageMagick**: `magick icon.svg -define icon:auto-resize=256,128,64,48,32,16 icon.ico`
- **Inkscape** → экспорт в PNG 256×256 → конвертация в `.ico`

## 🗂 Как пользоваться

### 1. Первый запуск

Открывается **Дашборд** — здесь статистика и последние расчёты. Если склад пуст, приложение покажет список материалов, которые нужно докупить.

### 2. Настройка ставок

**Настройки → Ставки и тарифы** — укажите свою ставку за час, тариф за электричество, мощность принтера, наценку по умолчанию. Значения будут подставляться в новые расчёты.

### 3. Свои материалы

**Справочник материалов → Новый материал** — добавьте материалы с ценами, остатками и минимальным запасом. Отметьте избранные звёздочкой.

### 4. Расчёт изделия

Выберите в сайдбаре «Изделия из гипса» / «Смолы» / «3D-печать»:

1. Заполните материал (вес, объём, тип)
2. Дополните работу, потери, упаковку
3. Добавьте декор (если есть)
4. Задайте наценку — увидите цену продажи
5. **Сохранить** — расчёт попадёт на дашборд
6. **Экспорт в PDF** — готовая смета для клиента

### 5. Библиотека знаний

**Библиотека → выберите категорию → читайте**

- `Ctrl` + клик по поиску — фильтр по всему сразу
- ⭐ — добавить в закладки
- ✏️ — редактировать (правки сохраняются)

### 6. Резервные копии

**Настройки → Данные → Создать резервную копию** — получите `gypsum_backup_*.json` в папке `backups/`. Восстановление — там же.
